# Plan check

纯本地的学习计划打卡工具。导入自己的计划，每天勾任务、记备注，看进度和日历热力图。

不联网、不注册、不上传任何数据。

当前版本 **1.1.0**，历史见 [CHANGELOG.md](CHANGELOG.md)。旧版安装包都保留在 `release\`。
内置背景图全部由程序生成，来源见 [NOTICE.md](NOTICE.md)；代码 MIT。

---

## 一、安装

下载：https://github.com/Yleyd/plan-check/releases

**安装包（推荐）**：双击 `PlanCheck-1.1.0-setup.exe`，选安装位置，可选桌面 / 开始菜单快捷方式。默认装到当前用户目录，不需要管理员权限。

卸载时问你**是否保留计划与打卡记录**，选「是」下次安装还能接着用（静默卸载一律保留）。

**绿色版**：解压 `PlanCheck-1.1.0-portable.zip`，双击 `PlanCheck.exe`。数据在 exe 同级的 `data\`，整个文件夹拷走就完成迁移。

## 二、第一次使用

首次打开是空的，四个入口：

| 按钮 | 说明 |
| --- | --- |
| **导入计划文件** | `.xlsx` `.csv` `.tsv` `.docx` `.pdf`（文字版）`.txt` `.md` |
| **下载计划模板** | 生成带表头和填写说明的 Excel，照着填再导入 |
| **手动新建** | 多行粘贴，一行一个任务 |
| **用示例计划** | 塞一份 5 天的示例，先试试 |

### 表格长这样

| 日期 | 第几天 | 科目 | 任务内容 | 小时 | 星级 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 2026-10-20 | 1 | 计算机组成原理 | 2.2 运算方法 | 3 | 3 | |
| 2026-10-20 | 1 | 数据结构 | 线性表 | 2 | 2 | |

- **日期**和**第几天**二选一。只写「第几天」时，导入会问起始日期。
- 列名不要求一字不差：`日期/date`、`科目/学科/subject`、`任务/内容/task` 都认，全角括号、表头带「（必填）」也能认。
- **小时**和**星级**可空，空着就不参与对应统计。
- 没有表头也行，程序按内容猜列；只有一两列也能导入。
- 一个 Excel 里多个工作表会全部读，「说明」「填写说明」这类表自动跳过。
- 「合计 / 总计 / 小计 / 说明：」这类汇总行自动跳过。

> 扫描件 PDF 读不出文字，请先转成 Excel。

## 三、四个页面

**今日** — 当天任务，点整行勾选；「全部完成」一键勾掉，「清空」一键取消；下方备注框记心得（`Ctrl+S` 保存）；`←` `→` 切换日期，可补打前几天的卡；顶部显示总进度、已完成任务数、连续打卡天数。

**进度** — 总览（任务数、完成数、总时长、已投入时长、连续天数）、各科完成率与小时投入（两套独立统计）、每周完成度。

**日历** — 整个计划周期的热力图。灰 = 未开始，蓝 = 部分完成，绿 = 全部完成，紫 = 今天。点格子跳到那天的今日页。

**设置** — 居中一张玻璃卡：导入计划文件 / 下载计划模板 / 换背景图 / 字号与选项（鼠标移上去略微放大），导出报告 / 立即备份 / 打开数据目录 / 恢复默认背景，底部显示数据目录位置。

## 四、多计划

顶部可切换计划，同时最多 5 个活跃，更多的自动归档，打卡记录各自独立保存。

覆盖导入时会尽量迁移能对上的旧记录，对不上的在预览页标红提示数量，可以改成「追加」再导一次。

## 五、数据在哪

```
<exe 所在目录>\
  data\
    index.json              计划索引
    plans\plan_xxx.json     计划内容
    plans\records_xxx.json  打卡记录
    backups\                每日自动备份（保留 14 份）
    assets\user\            自己换的背景图
    logs\                   运行日志
```

exe 放在 `C:\Program Files` 这类不可写位置时，自动回退到 `%APPDATA%\PlanCheck\`，具体路径在设置页有显示。

备份每次启动自动做一份，保留最近 14 天。恢复：把 `backups\` 里的 json 拷回 `plans\` 覆盖同名文件。

## 六、换背景图

设置 →「换背景图」。启动画面 1 张，今日 / 进度 / 日历 / 设置各 1 张，互不影响。只收 `.jpg` `.png`，会自动修正手机照片方向、缩到 2560 宽，选完立刻生效。

内置 6 张原创图：极光·蓝、光环·紫、星云·紫、对撞·青红、流光·青、同心环·蓝，都由 `tools/genart.py` 用代码画出，不含第三方素材。也可以手动把图丢进 `data\assets\user\`，文件名对应 `start` / `today` / `prog` / `cal` / `set`。

## 七、命令行

```
PlanCheck.exe                 正常启动（带启动动画）
PlanCheck.exe --nosplash      跳过启动动画
PlanCheck.exe --selftest      跑 38 项自检，不开窗口
PlanCheck.exe --smoke         开窗 6 秒后自动关闭
```

## 八、常见问题

**导入后任务行是空的？** 多半是只写了「第几天」没有日期，导入时需指定起始日期。也可能是表格有合并单元格导致列错位。

**Excel 里的日期变成数字（如 46300）？** 1.0.4 起能直接识别 Excel 的日期对象与序列号；也可以把那列格式改成「日期」再另存。

**改了模板就导入不进来？** 1.0.4 起大幅放宽：多工作表、增删列、表头带备注、全角括号、顶部大标题行、`2.5h` / `1小时`、`★★★` / `三星`、汇总行、只有一两列的表格都能处理。还不行就把前几行发出来。

**PDF 导入失败？** 只支持文字版。能选中文字的就是文字版，选不中是扫描件，需要 OCR 或手动整理成 Excel。

**换图后没变化？** 换图立即生效，没看到就切一下页面或重启。各页面的图互相独立，换进度页不影响启动画面。

**点 × 一次退不掉？** 1.0.4 已修。

**能多台电脑同步吗？** 不能，纯本地。迁移就把 `data\` 整个拷过去。
