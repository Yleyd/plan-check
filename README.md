# Plan check

一个纯本地的学习计划打卡工具。导入自己的计划（Excel / CSV / Word / 文本 / 手动粘贴），每天勾任务、记备注，看进度和日历热力图。

不联网、不注册、不上传任何数据。

当前版本 **1.0.3**。版本历史见 [CHANGELOG.md](CHANGELOG.md)，旧版本的安装包与绿色版都保留在 `release\` 里。
内置的 6 张背景图全部由程序生成，来源与许可见 [NOTICE.md](NOTICE.md)（代码 MIT）。

---

## 一、安装

### 方式一：安装包（推荐）

双击 `PlanCheck-1.0.3-setup.exe`：

1. 选择安装位置（默认装到当前用户目录，无需管理员权限）
2. 勾选是否创建桌面 / 开始菜单快捷方式
3. 完成后可直接运行

**卸载**：开始菜单 →「卸载 Plan check」，或设置 → 应用 → Plan check。
卸载时会问你**是否保留学习计划与打卡记录**，选「是」下次安装还能接着用。
（静默卸载 `/VERYSILENT` 一律保留数据，不会误删。）

### 方式二：绿色版

解压 `PlanCheck-1.0.3-portable.zip` 到任意文件夹，双击 `PlanCheck.exe` 即可。
数据保存在 exe 同级的 `data\` 文件夹里，整个文件夹拷走就完成迁移。

## 二、第一次使用

首次打开是空的，有四个入口：

| 按钮 | 说明 |
| --- | --- |
| **导入计划文件** | 支持 `.xlsx` `.csv` `.tsv` `.docx` `.pdf`（文字版）`.txt` `.md` |
| **下载计划模板** | 生成一个带表头和填写说明的 Excel，照着填再导入 |
| **手动新建** | 直接把计划多行粘贴进来，一行一个任务 |
| **用示例计划** | 塞一份 5 天的示例，先玩玩看 |

### 计划表格长这样

| 日期 | 第几天 | 科目 | 任务内容 | 小时 | 星级 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 2026-10-20 | 1 | 计算机组成原理 | 2.2 运算方法 | 3 | 3 | |
| 2026-10-20 | 1 | 数据结构 | 线性表 | 2 | 2 | |

- **日期**和**第几天**二选一即可。只写「第几天」时，导入会问你计划从哪天开始。
- 列名不要求一字不差，`日期/date`、`科目/学科/subject`、`任务/内容/task` 这些同义词都认。
- **小时**和**星级**都可以空着，空着就不参与对应统计。
- 没有表头也行，程序会按内容猜列。

> 扫描件 PDF 读不出文字，请先转成 Excel。

## 三、四个页面

### 今日

- 当天所有任务，点整行即可勾选
- 「全部完成」一键勾掉今天所有任务，「清空」一键取消
- 下方备注框记今天的心得，`Ctrl+S` 保存
- `←` `→` 切换日期，可以补打前几天的卡
- 顶部显示总进度、已完成任务数、连续打卡天数

### 进度

- 总览：总任务数、已完成、总时长、已投入时长、连续天数
- 各科：每科的任务完成率与小时投入（两条独立的统计）
- 每周：7 周完成度一览

### 日历

- 一整个计划周期的热力图，一眼看出哪几天断了
- 灰 = 未开始，蓝 = 部分完成，绿 = 全部完成，紫 = 今天
- 点任意格子跳到那天的今日页

### 设置

居中一张玻璃卡，所有入口都在这里：

- 导入计划文件 / 下载计划模板 / 换背景图 / 字号与选项（2×2 主按钮，鼠标移上去会略微放大）
- 导出进度报告 / 立即备份 / 打开数据目录 / 恢复默认背景
- 底部显示当前数据目录位置（便携 / `%APPDATA%` 回退）

## 四、多计划

顶部可以切换计划。同时最多 5 个活跃计划，更多的自动归档。
每个计划的打卡记录独立保存，切回去不会丢。

导入时如果选了「覆盖」，程序会尽量把能对上的旧记录迁移过去，
对不上的会在预览页标红提示数量，你可以改成「追加」再导一次。

## 五、数据在哪

便携模式（exe 目录可写）：

```
<exe 所在目录>\
  data\
    index.json              计划索引
    plans\plan_xxx.json     计划内容
    plans\records_xxx.json  打卡记录
    backups\                每日自动备份（保留 14 份）
    assets\user\            你自己换的背景图
    logs\                   运行日志
```

如果 exe 放在 `C:\Program Files` 这种不可写的位置，会自动回退到
`%APPDATA%\PlanCheck\`，具体路径在设置页顶部有显示。

备份：每次启动自动备份一份，保留最近 14 天。
恢复：把 `backups\` 里的 json 拷回 `plans\` 覆盖同名文件即可。

## 六、换背景图

设置 →「换背景图」：

- 启动画面：1 张
- 今日 / 进度 / 日历 / 设置：各 1 张
- 只收 `.jpg` `.png`，会自动修正手机照片的方向、缩到 2560 宽
- 选完立刻生效，不用重启
- 随时可以「恢复默认背景」

内置可选 6 张原创图：极光·蓝、光环·紫、星云·紫、对撞·青红、流光·青、同心环·蓝。
这些图都是 `tools/genart.py` 用代码画出来的，不含第三方素材。

也可以手动把图片丢进 `data\assets\user\`，文件名对应
`start` / `today` / `prog` / `cal` / `set`。

## 八、常见问题

**导入后任务行是空的？**
先看是不是只有「第几天」没有日期，那样需要在导入时指定起始日期。
另外检查一下表格里是否有合并单元格，合并单元格会导致列错位。

**Excel 里的日期变成了数字（如 46300）？**
在 Excel 里把那一列格式改成「日期」再另存，或者直接写成 `2026-10-20`。

**PDF 导入失败？**
只支持文字版 PDF。用 PDF 阅读器选中文字如果能选中，就是文字版；
选不中就说明是扫描件，需要 OCR 或者手动整理成 Excel。

**换图后没变化？**
换图是立即生效的，如果没看到，切一下页面或重启程序。

**能不能多台电脑同步？**
不能，纯本地。要迁移就把 `data\` 整个文件夹拷过去。
